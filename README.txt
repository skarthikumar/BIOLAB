KCET BioLab Copilot - offline web app
Department of Biotechnology, Kamaraj College of Engineering & Technology
Created by Dr. S. Karthikumar, Associate Professor, Biotechnology (karthikumarbt@kamarajengg.edu.in)

HOW TO PUT THIS APP ONLINE (one time, free):
Upload ALL files and folders in this folder (index.html, app.js, sw.js, manifest.webmanifest,
data, icons, img) to a free static web host such as GitHub Pages. The step-by-step guide is in
"KCET BioLab Copilot - Installation Guide.pdf", Part D.

The app must be served over https (GitHub Pages does this automatically).
Opening index.html directly from a computer folder will NOT work - it must be hosted.

WHAT IS INSIDE
index.html, app.js ......... the app
sw.js ...................... keeps the app on the phone for offline use
manifest.webmanifest ....... app name and icon for "Install" / "Add to Home screen"
data/manuals.json .......... text of the 9 lab manuals (129 experiments), used for answers
icons/, img/ ............... college emblem and banner
